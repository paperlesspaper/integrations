# Calendar screenshots

224 fresh browser captures, each also processed with the native Spectra 6 palette and error diffusion. Fictional data only. The simulated palette does not replace a hardware check.

[Interactive gallery](index.html) · [Render results](results.json) · [Fixtures](fixtures.json)

## Implementation status

- **Personal options in all seven integrations:** day summary, local automatic icon suggestions, personal heading/subtitle and automatic, standard, compact or spacious information density. Each can be configured independently.
- **Available options:** all ten calendar views below in Google, Apple, Outlook, Nextcloud, Proton, CalDAV and Webcal.
- **Implemented in Google Calendar:** automatic image discovery and `[icon:…]` shortcodes, independently switchable. A missing image does not remove an explicit icon.
- **Concepts only:** Event magazine, event programme and event poster. Their screenshots come from the separate HTML prototypes; these three layouts are not selectable integration options yet.
- **Not included:** authorized access to private Drive images, deployment or changes to connected calendars.

## Reproduce

```sh
node scripts/render-calendar-screenshots.mjs
node scripts/build-calendar-screenshot-gallery.mjs
```

The render script starts temporary local servers on ports 3390 and 3391 and uses installed Chrome (or `CHROME_BIN`). It waits for ready markers, fonts and images, checks browser errors and icon artwork, then writes the PNGs here and refreshes catalog screenshot references in the seven provider manifests. Temporary originals live under `output/playwright/calendar-repository/`.

The shared views use the real Google adapter with a fixed 24 July 2026 fixture. Provider catalog previews use the real render pages and synthetic normalized API responses at each variant's configured date; they do not verify live provider authentication. Image-discovery examples use deterministic mocked page metadata and image responses. The event-layout concepts use their separate 2–8 October 2026 fixture.

The 7.3-inch captures are 800 × 480 / 480 × 800. The 13-inch captures are 1600 × 1200 / 1200 × 1600. Click an image for the full-resolution processed PNG, or use its Browser PNG link.
