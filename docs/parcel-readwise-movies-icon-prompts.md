# Generated integration icons

Generated on 2026-09-27 using the built-in ImageGen tool (one independent call per icon). ImageShine was not available in this session. Prompts follow the canonical paperlesspaper-openintegration README's integration-icon template.

The generated square PNGs are saved at `applications/<slug>/assets/icon.png` and referenced by each manifest. Original output dimensions are 1254×1254; the README recommends 1024×1024 but does not require that exact size. Images are copied without raster postprocessing, preserving the generated alpha channel. Their content and transparency were inspected on both light and dark surfaces. The earlier `icon.svg` files are retained as vector drafts and are not the source of the generated PNGs.
